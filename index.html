Save & backup

Your plan saves by itself, but only in this browser on this device. If saving ever fails, a red “Not saved” warning appears at the top until it works again. It is not stored online, it does not sync to other devices, and clearing your browser data can erase it. Download a backup file to keep a copy you control.

Opening a file replaces the plan on screen. The file is checked first; if anything is wrong, nothing changes. Your current plan is kept as a backup.
